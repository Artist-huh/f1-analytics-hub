# Скриншоты экранов

Снимки делает `scripts/shoot.sh`: запускает приложение сразу на нужном экране (`scripts/launch.py`),
ждёт отрисовки и снимает окно (`scripts/capture.ps1`, PrintWindow — работает и под другими окнами).
Только Windows: нужны `venv` проекта, PowerShell и Git Bash.

## Как снять

Папку для снимков бери во временной директории сеанса (scratchpad), не в репозитории — снимки не коммитятся:

```bash
sh .claude/skills/shots/scripts/shoot.sh "<scratchpad>/shots" home tab0
```

Аргументы: папка, имя файла (без `.png`), экран, затем ширина и высота окна (по умолчанию 440×880 — телефон;
компьютер — `1100 800`). Снимается только то, что влезло в окно, а выше монитора окно не откроется
(высота упрётся примерно в 1100 px) — низ длинной страницы снимай с прокруткой `SCROLL=end` (см. ниже).
Потом открой `<scratchpad>/shots/home.png` инструментом Read и оцени картинку.

Один снимок — около 25 с. Окно Flet одно, и после каждого снимка процессы `flet.exe` закрываются, поэтому
снимки идут строго по очереди: параллельные запуски убьют окна друг друга. Несколько экранов — одной
командой (таймаут Bash поставь с запасом, ~30 с на снимок):

```bash
for s in tab0 tab1 sub:live; do sh .claude/skills/shots/scripts/shoot.sh "<scratchpad>/shots" "${s#sub:}" "$s"; done
```

| SHOT | Экран |
|------|-------|
| `tab0` … `tab4` | Главная, Чемпионат, Календарь, Пилоты, Ещё |
| `sub:live` | Live Timing |
| `sub:driver_detail` | страница лидера чемпионата |
| `sub:team` | страница первой команды |
| `sub:compare`, `sub:settings`, `sub:history`, `sub:title`, `sub:predict`, `sub:strategy`, `sub:favorites`, `sub:race_strategy` | подэкраны |

«Все» — пять вкладок плюс `sub:live`, `sub:driver_detail`, `sub:team`, `sub:compare`, `sub:settings`
(около 4–5 минут). Если правка затронула один экран — снимай его, а не всё подряд.

## Тема, шрифт, огни — переменные перед командой

Действуют только на этот запуск: настройки пользователя не меняются.

- `THEME=light`, `THEME=oled`, `THEME=team:Mercedes` — тема. Правку цвета проверяй в тёмной, светлой и
  теме команды: в светлой и командной контраст ломается чаще всего.
- `FONT=1.15` или `FONT=1.3` — «Крупный» и «Очень крупный» текст. Правку вёрстки проверяй с `FONT=1.3` на
  ширине 440 (а для узких мест — `360 640`): там текст обрезается и переносится первым.
- `LIT=0..5` — сколько стартовых огней горит в герое главной, независимо от даты гонки.
- `SCROLL=end` — прокрутить экран до конца, `SCROLL=600` — на 600 px вниз. С прокруткой нужен `WAIT=26`:
  она срабатывает через 2 с после отрисовки.
- `WAIT=30` — дольше ждать отрисовки, если на снимке пустое окно (первый запуск после установки
  зависимостей медленнее).

```bash
THEME=light FONT=1.3 sh .claude/skills/shots/scripts/shoot.sh "<scratchpad>/shots" driver-light-xl sub:driver_detail
```

«window not found» — окно не успело открыться: увеличь `WAIT`; причину смотри в `<имя>.log` рядом со снимком
(там же трассировка, если экран упал).

## Что проверять на снимке

Правила проекта (подробно — в `.claude/agents/ui-reviewer.md`): красный — только LIVE, огни и главные
действия; текст читается во всех темах; нет заглавных надписей и склеек через «·»; зоны нажатия не меньше
48 dp; ничего не обрезано на ширине телефона. Пустые блоки на снимке — это часто отсутствие данных в локальной
базе, а не ошибка вёрстки: прежде чем чинить, загляни в `.log`.

В ответе пользователю назови, что снято (экран, тема, шрифт, ширина), что видно и что не так — коротко,
по пунктам; пути к снимкам — полностью.
