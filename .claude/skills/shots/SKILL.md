# Скриншоты экранов

Снимки делает `scripts/shoot.sh`: запускает приложение сразу на нужном экране (`scripts/launch.py`),
ждёт отрисовки и снимает окно (`scripts/capture.ps1`, PrintWindow — работает и под другими окнами).
Только Windows: нужны `venv` проекта, PowerShell и Git Bash.

## Как снять

Папку для снимков бери во временной директории сеанса (scratchpad), не в репозитории:

```bash
sh .claude/skills/shots/scripts/shoot.sh "<scratchpad>/shots" home tab0
```

Потом открой `<scratchpad>/shots/home.png` инструментом Read и оцени картинку.
Снимки по очереди, не параллельно: окно Flet одно, после каждого снимка процессы `flet.exe` закрываются.

| SHOT | Экран |
|------|-------|
| `tab0` … `tab4` | Главная, Чемпионат, Календарь, Пилоты, Ещё |
| `sub:live` | Live Timing |
| `sub:driver_detail` | страница лидера чемпионата |
| `sub:team` | страница первой команды |
| `sub:compare`, `sub:settings`, `sub:history`, `sub:title`, `sub:predict`, `sub:strategy` | подэкраны |

Размер окна: 4-й и 5-й аргументы (по умолчанию 440×880, телефон). Компьютер — `1100 800`.

Особые случаи:
- `LIT=0..5` — превью стартовых огней героя главной (сколько горит), независимо от даты гонки.
- `WAIT=30` — если на снимке пустое окно (первый запуск после установки зависимостей медленнее).
- «window not found» — окно не успело открыться: увеличь `WAIT`; смотри `<имя>.log` рядом со снимком.

## Что проверять на снимке

Правила проекта (подробно — в `.claude/agents/ui-reviewer.md`): красный — только LIVE, огни и главные
действия; текст читается в обеих темах; нет заглавных надписей и склеек через «·»; зоны нажатия не меньше 48 dp;
ничего не обрезано на ширине телефона 440.
