## ✨ Возможности

### 🏁 Главная
- **Live-таймер** до следующей гонки с обратным отсчетом
- Топ-5 пилотов чемпионата с живыми обновлениями
- Подиум последней гонки
- Быстрый доступ к ключевым функциям

### 🏆 Чемпионат
- **Турнирная таблица пилотов** — позиции, очки, отставание от лидера
- **Турнирная таблица команд** — борьба конструкторов
- Фильтрация и сортировка
- Цветовое кодирование по командам

### 👤 Пилоты
- **Карточки всех гонщиков** с фото и статистикой
- Поиск по имени, команде, стране
- Фильтр по командам с цветными чипами
- Клик на пилота → детальная страница

### 📊 Детальная страница пилота
- Полная статистика сезона (очки, победы, подиумы, DNF)
- **График динамики очков** по гонкам
- История результатов с цветовыми индикаторами
- Информация о команде и стране

### ⚡ Сравнение пилотов
- **Head-to-head** анализ двух гонщиков
- Визуальное сравнение статистики
- История личных встреч
- Кто финишировал выше в каждой гонке

### 📅 Календарь
- **Интерактивный календарь** всех гонок сезона
- Следующая гонка выделена с таймером
- Характеристики трасс (длина, кругов, DRS-зоны)
- Флаги стран и информация о локациях
- Фильтр: предстоящие / завершенные

### ⭐ Избранное
- Добавляйте любимых пилотов для быстрого доступа
- Агрегированная статистика избранных
- Уведомления об их результатах (планируется)

### 📈 Аналитика (в разработке)
- Интерактивные графики Flet Charts
- Сравнение команд
- Анализ трендов
- Статистика по трассам

## 🚀 Запуск

### Из исходников

```bash
# Клонировать репозиторий
git clone https://github.com/Artist-huh/f1-analytics-hub.git
cd f1-analytics-hub

# Установить зависимости
pip install -r requirements.txt

# Запустить приложение
python main.py

# Или в веб-режиме
flet run --web main.py
```

1. Перейти в [Releases](https://github.com/Artist-huh/f1-analytics-hub/releases)
2. Скачать `F1AnalyticsHub.exe`

## 🌐 Источники данных

- **API**: [Jolpica F1 API](https://github.com/jolpica/jolpica-f1) — бесплатный, открытый API Формулы-1
- **Кэширование**: SQLite — все данные хранятся локально
- **Офлайн-режим**: работает без интернета с последними сохраненными данными

### Обновление данных

- **Автоматически**: каждые 5 минут (настраивается)
- **Вручную**: кнопка "Обновить" в настройках
- **При запуске**: загружает свежие данные если есть интернет

## Работа без сети
Данные хранятся в SQLite и обновляются в фоне (интервал — в «Настройках»). Без сети приложение
показывает последнюю сохранённую копию с сообщением об ошибке. Для первого запуска без интернета
создай снимок: `python -m services.seed export --refresh` (файл `data/seed.json`).
Сборка `.exe` — см. `BUILD.md`.

## Структура
    main.py                    оболочка: навигация, перерисовка, фоновые потоки
    theme.py                   цвета, шрифт, цвета команд и шин
    services/log.py            журнал (консоль + файл с ротацией)
    services/seed.py           начальный снимок данных (экспорт/импорт)
    services/jolpica.py        HTTP-клиент: таймауты, retry, ограничение частоты, разбор JSON
    services/db.py             SQLite: кэш API + избранное и настройки
    services/f1_api.py         фасад для UI: чтение из БД, фоновое обновление, статус
    ui/state.py                состояние приложения и действия пользователя
    ui/widgets.py, ui/fmt.py   общие элементы и форматирование
    ui/screens/                home, season (чемпионат+календарь), driver, more
    tests/                     python -m unittest discover -s tests -t .

БД создаётся автоматически (`~/.ferrari_leclerc_hub/f1_hub.db`, во Flet-сборке — папка
данных приложения). `F1_HUB_DB` задаёт свой путь.

## Таблицы БД
    meta, standings, constructor_standings, race_results, schedule   — кэш API
    favorites, settings                                              — данные пользователя
