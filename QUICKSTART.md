# 🚀 Быстрый старт

## Вариант 1: Запуск из исходников (5 минут)

### Windows

```batch
# Двойной клик на файл
start.bat
```

Или вручную:

```bash
# 1. Установить зависимости (версии закреплены в constraints.txt)
pip install -r requirements.txt -c constraints.txt

# 2. Запустить
python main.py
```

### macOS

```bash
python3.11 -m venv venv && source venv/bin/activate
pip install -r requirements.txt -c constraints.txt
python main.py
```

Linux не собирается и не проверяется: запуск из исходников, скорее всего, работает, но не гарантирован.

## Вариант 2: Сборка .exe (10 минут)

### Автоматическая сборка (рекомендуется)

```batch
# Windows - двойной клик
build.bat
```

Скрипт сам прогонит тесты, обновит снимок данных и соберёт `dist/F1AnalyticsHub.exe`
через `flet pack`. Подробности и ручная команда — в [BUILD.md](BUILD.md).

## Вариант 3: Скачать готовый .exe

1. Перейти в [Releases](https://github.com/Artist-huh/f1-analytics-hub/releases)
2. Скачать архив своей системы: `…-Windows.zip`, `…-macOS.zip`, APK для Android или `…-iOS-unsigned.ipa`
3. Распаковать и запустить (Python не нужен)

**macOS:** приложение не подписано сертификатом Apple, поэтому при первом запуске macOS напишет, что не может
проверить разработчика. Откройте его через правый клик → «Открыть» → «Открыть» (один раз) или в «Системных
настройках» → «Конфиденциальность и безопасность» → «Всё равно открыть».

## Первый запуск

При первом запуске приложение:
1. Создаст базу данных `%USERPROFILE%\.f1_analytics_hub\f1_hub.db`
2. Заполнит её встроенным снимком `data/seed.json`, чтобы экраны сразу были с данными
3. Откроет главный экран и в фоне загрузит свежие данные Ф1 (нужен интернет)

**Без интернета**: приложение работает на встроенном снимке или последних сохранённых данных

## Навигация

- **Главная** — следующая гонка, топ-5 пилотов
- **Чемпионат** — турнирные таблицы
- **Календарь** — все гонки сезона
- **Пилоты** — карточки, поиск, сравнение
- **Ещё** — настройки, аналитика

---

## Горячие клавиши

| Клавиша | Действие |
|---------|----------|
| `F5` | Обновить данные |
| `Ctrl+F` | Поиск пилота |
| `Ctrl+K` | Сравнение |
| `Ctrl+L` | Live Timing |
| `Ctrl+M` | Мини-виджет |
| `Ctrl+H` | Свернуть окно |
| `Esc` | Назад |

На macOS вместо `Ctrl` подходит `Cmd`, кроме `Cmd+M` и `Cmd+H`: это системные «Свернуть» и «Скрыть».

## Решение проблем

### "ModuleNotFoundError: No module named 'flet'"

```bash
pip install -r requirements.txt -c constraints.txt
```

### "Python не найден"

Установите Python 3.11 с [python.org](https://python.org)

При установке отметьте **"Add Python to PATH"**

### Приложение не запускается

1. Проверьте версию Python: `python --version` (нужна 3.11)
2. Переустановите зависимости: `pip install -r requirements.txt -c constraints.txt --force-reinstall`
3. Запустите с логами: `python main.py > log.txt 2>&1`

### Не загружаются данные

- Проверьте интернет-соединение
- API может быть недоступен — подождите 5 минут
- Приложение работает с кешем в `%USERPROFILE%\.f1_analytics_hub\f1_hub.db`
- Подробности ошибок — в журнале `%USERPROFILE%\.f1_analytics_hub\f1_hub.log`
