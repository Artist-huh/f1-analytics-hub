# 🚀 Быстрый старт

## Вариант 1: Запуск из исходников (5 минут)

### Windows

```batch
# Двойной клик на файл
start.bat
```

Или вручную:

```bash
# 1. Установить зависимости
pip install flet requests

# 2. Запустить
python main.py
```

### macOS / Linux

```bash
# 1. Установить зависимости
pip3 install flet requests

# 2. Запустить
python3 main.py
```

## Первый запуск

При первом запуске приложение:
1. Создаст базу данных `data/f1.db`
2. Загрузит актуальные данные Ф1 (нужен интернет)
3. Откроет главный экран

**Без интернета**: приложение покажет demo-данные

---

## Навигация

- **Главная** — следующая гонка, топ-5 пилотов
- **Чемпионат** — турнирные таблицы
- **Календарь** — все гонки сезона
- **Пилоты** — карточки, поиск, сравнение
- **Ещё** — настройки, аналитика

## Решение проблем

### "ModuleNotFoundError: No module named 'flet'"

```bash
pip install flet requests
```

### "Python не найден"

Установите Python 3.10+ с [python.org](https://python.org)

При установке отметьте **"Add Python to PATH"**

### Приложение не запускается

1. Проверьте версию Python: `python --version` (должно быть ≥ 3.10)
2. Переустановите зависимости: `pip install --force-reinstall flet requests`
3. Запустите с логами: `python main.py > log.txt 2>&1`

### Не загружаются данные

- Проверьте интернет-соединение
- API может быть недоступен — подождите 5 минут
- Приложение работает с кешем в `data/f1.db`
