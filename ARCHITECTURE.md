# F1 Analytics Hub — архитектура

Десктоп- и мобильное приложение на Python + [Flet 1.0](https://flet.dev) (интерфейс рисует Flutter).
Данные — из открытых API, хранятся в SQLite, интерфейс читает только локальную базу и поэтому
открывается мгновенно и работает без сети.

```
            Jolpica F1 API          OpenF1            media.formula1.com, flagcdn.com
                  │                    │                          │
          services/jolpica.py   services/media.py ───────────────┘  (картинки → дисковый кэш)
                  │                    │
                  └──────► services/db.py (SQLite) ◄── services/seed.py (снимок для первого запуска)
                                   │
                           services/f1_api.py   фасад: чтение из БД, фоновое обновление, статус
                                   │
                           services/stats.py    статистика сезона (чистые функции)
                                   │
                              ui/state.py       состояние, навигация, сравнение, картинки
                                   │
                    ui/screens/* + ui/components.py + ui/widgets.py
                                   │
                                main.py         окно, нижнее меню, смена экранов, «назад»
```

## Данные

| Таблица | Что | Обновление |
|---------|-----|-----------|
| `standings` | личный зачёт: позиция, очки, победы, команда, национальность, номер | каждые 5/10/30 мин |
| `constructor_standings` | Кубок конструкторов | каждые 5/10/30 мин |
| `race_results` | результаты всех гонок сезона по всем пилотам (место, старт, очки, статус, ранг быстрого круга) | один раз на новый этап зачёта; если результаты ещё не опубликованы — повтор через 30 мин; иначе раз в 6 ч |
| `qualifying`, `sprint_results` | позиции в квалификациях (поулы, средняя квалификация), очки спринтов (график очков) | вместе с результатами |
| `schedule` | календарь с временем сессий (UTC) | раз в 6 ч или вручную |
| `driver_media` | код пилота → идентификатор портрета formula1.com (из OpenF1) | раз в сутки, сбой не критичен |
| `archive` | JSON по ключу: сезоны прошлых лет (`season:<год>`), история трасс (`circuit:<id>`) | по запросу: прошлые сезоны бессрочно, текущий — 6 ч, трасса — неделя |
| `favorites`, `settings` | данные пользователя — не стираются при очистке кэша и смене схемы (тема, уведомления, интервал) | — |

Схема версионируется (`PRAGMA user_version`). При смене версии кэш API пересоздаётся и скачивается
заново, избранное и настройки сохраняются. База из старой папки `~/.ferrari_leclerc_hub` переносится
в `~/.f1_analytics_hub` при первом запуске.

Правила:
- **Только реальные данные.** Нет сети и нет кэша — пустой экран с кнопкой «Обновить», а не выдуманные цифры.
- **Пустой ответ не стирает копию** (например, сезон ещё не начался).
- **Сбой сети** не роняет приложение: показывается сохранённая копия и баннер, повтор с паузой 15, 30, 60… с.
- **Один фоновый поток** на процесс, у него может быть много подписчиков (вкладки в веб-режиме).

## Картинки (`services/media.py`)

- Портрет пилота: `common/f1/<сезон>/<команда>/<id>/<сезон><команда><id>right.webp` — прозрачный фон,
  обрезка «голова и плечи» для аватара и «по пояс» для крупного портрета; `<id>` (например, `chalec01`)
  берётся из OpenF1. Нет портрета за сезон — сохраняется запасное фото из OpenF1; нет ничего — инициалы.
- Логотип и болид команды: `…/<сезон><команда>logowhite.webp`, `…carright.webp`.
- Флаги: `flagcdn.com/w80/<iso>.png` (национальность пилота или страна этапа → ISO-код в `design_system`).
- Интерфейс получает байты из кэша (`<папка данных>/media`) или из встроенной папки `data/media`,
  иначе — URL (картинку загрузит Flutter, а `prefetch` сохранит её к следующему запуску).

## Данные по запросу, live и уведомления

- **`services/archive.py`** — история: сезон любого года и статистика трассы загружаются в фоне, когда
  пользователь их открыл, и сохраняются в `archive`. Чемпионы 1950–2025 встроены (`data/champions.json`,
  собирает `tools/build_champions.py`): у API нет запроса «все чемпионы», а 76 запросов упираются в лимит.
- **`services/live.py`** — снимок последней сессии OpenF1 (позиции, интервалы только за последние минуты,
  стинты → шины и их возраст, пит-стопы, сообщения дирекции). В БД не пишется; пока открыт экран,
  `AppState.watch_live` обновляет его раз в 10 с во время сессии и раз в 5 минут после.
- **`services/notify.py`** — что отправлять (чистые функции: сессии в ближайший час, итог избранных) и
  как: desktop-notifier, Android NotificationManager через pyjnius или плашка. Проверка — раз в 30 с
  из `main.tick`; отправленное запоминается в `settings`.

## Темы

`design_system.apply_theme()` меняет палитру на месте (тёмная, светлая, акцент — цвет команды).
Экраны берут цвета через `from design_system import *`, поэтому `ui/theming.py` после этого
перезагружает модули интерфейса (`importlib.reload`), а `main.refresh_screens()` заново собирает
таблицу экранов. Текст на цветных фонах — `ON_COLOR`/`INK`, чтобы он читался в любой теме.

## Интерфейс

- **Экраны** — функции `build(state) -> Control`. Вкладки: Главная, Чемпионат, Календарь, Пилоты, Ещё;
  подэкраны: страница пилота, сравнение, избранное, стратегия, настройки.
- **Перерисовка из фоновых потоков** идёт через `page.run_task` (`main.run_on_ui`): во Flet 0.80+
  `page.update()` из обычного потока не будит цикл событий. Несколько запросов подряд сливаются в одну перерисовку.
- **Анимации**: смена экрана — `AnimatedSwitcher` (только при переходе, не при обновлении данных);
  элементы нового экрана появляются «лесенкой» (`FadeIn`); карточки — подъём, тень и подсветка рамки
  цветом команды при наведении, «рябь» при нажатии.
- **Адаптивность**: ширина контента ≤ 1100 px; < 480 px — компактные строки (фамилия вместо полного
  имени, сжатый индикатор сети), < 400 px — подписи меню только у активной вкладки; сетки
  `ResponsiveRow` (1 колонка на телефоне, 2–3 на компьютере); зоны нажатия ≥ 48 px; `SafeArea`.
- **«Назад»**: стек подэкранов; системная кнопка Android — подэкран → вкладка → «Главная» → выход;
  на компьютере — `Esc`.

## Дизайн-система (`design_system.py`)

Палитра F1 (`F1_RED #E10600`, `BG #15151E`, поверхности `#1E1E29…#31313E`), шрифты Exo 2
(`FONT_HEADING`, `FONT_DISPLAY_ITALIC` — крупные цифры), отступы, скругления, тени (`shadow`, `glow`),
цвета и медиа-идентификаторы 12 команд, таблицы «национальность/страна → ISO-код».
