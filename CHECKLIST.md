## 🚀 Что можно сделать прямо сейчас

### 1. Запустить приложение

```bash
python main.py
```

или

```bash
start.bat  # Windows двойной клик
```

### 2. Собрать .exe файл

```bash
build.bat  # тесты -> снимок данных -> flet pack
```

Результат: `dist/F1AnalyticsHub.exe` (~60 МБ). Подробности — [BUILD.md](BUILD.md).

## 📦 Распространение

### GitHub Release

1. Создать релиз на GitHub
2. Прикрепить собранный .exe
3. Пользователи скачивают без установки Python

### Microsoft Store (опционально)

1. Обернуть в MSIX пакет
2. Отправить в Microsoft Partner Center
3. Публикация в Windows Store

### Chocolatey (опционально)

1. Создать nuspec-файл
2. Отправить пакет в Chocolatey
3. Установка через `choco install f1-analytics-hub`

---

## 🐛 Известные ограничения

- API данные обновляются раз в ~10 минут (ограничение Jolpica)
- Изображения пилотов — placeholder-ы (нужен реальный источник)
- Нет live-телеметрии (требует другое API)
- Графики статичные (нет hover-интерактивности)
