# Браузеры

**Не применимо.** У приложения нет веб-сборки. Его собирают только как настольное приложение (Windows, macOS)
и мобильное (Android, iPhone): `flet build web` в CI не запускается, а `pyproject.toml` веб-цель не описывает.

| Браузер | Статус | Причина |
|---|---|---|
| Chrome, Edge, Firefox, Safari, Opera, Samsung Internet | Not Tested | Веб-версии нет |

Почему веб-сборку не стоит добавлять без отдельной работы:

- Live Timing подключается к `livetiming.formula1.com` по WebSocket с cookie согласования. Из браузера это
  блокирует CORS.
- Расшифровка радио работает на устройстве (whisper.cpp, ML Kit). В браузере этих моделей нет.
- Уведомления, виджет и будильники завязаны на систему устройства.

Если веб понадобится, начинать стоит с плана: какие экраны нужны в браузере и через что идут данные (свой
прокси против правила «без сервера»).
