# Анализ проекта

Дата аудита: 4 ноября 2026. Версия: 2.6.0 (ветка `main`, коммиты `e1f5dbc` … `9d3606b`).

## Что это

F1 Analytics Hub — приложение со статистикой Формулы-1: чемпионат, календарь, пилоты и команды, разбор
гонок, Live Timing, радио команд с офлайн-расшифровкой и переводом, прогнозы, уведомления, виджет Android.
Интерфейс — только на русском.

| | |
|---|---|
| Язык и фреймворк | Python 3.11, Flet 1.0.5 (Flutter 3.44.8) |
| Платформы сборки | Windows (`.exe`, PyInstaller), macOS (`.app`), Android (APK, 3 ABI), iPhone (IPA без подписи, симулятор) |
| Веб | Не собирается и не поддерживается (см. [BROWSER_COMPATIBILITY.md](BROWSER_COMPATIBILITY.md)) |
| Хранение | SQLite на устройстве (WAL, новое соединение на запрос) |
| Сервер | Нет. Все данные — из открытых бесплатных источников, прямо с устройства |

## Состав

| Часть | Где | Что делает |
|---|---|---|
| Оболочка | `main.py` | Навигация, смена экранов, «назад», темы, мини-окно, горячие клавиши, самопроверки для CI |
| Дизайн-система | `design_system.py` | Цвета, шрифты, отступы, темы (тёмная, светлая, OLED, тема команды), расчёт контраста |
| Экраны | `ui/screens/` (25 модулей) | Главная, Чемпионат, Календарь, Пилоты, Ещё и подэкраны |
| Состояние | `ui/state.py` | Данные экранов, уведомления, оставшиеся этапы, клавиши |
| Данные | `services/` | `f1_api` (кэш в SQLite), `jolpica`, `f1live` (SignalR), `track_map`, `radio`, `notify`, `alerts`, `widget`, `report`, `net` |
| Расширения Flutter | `packages/flet_home_widget`, `packages/flet_radio` | Виджет Android (Java); whisper.cpp + ML Kit + декодер miniaudio (C, FFI) |
| Проверки сборок | `tools/` | Запуск `.exe`/`.app`, эмулятор Android, симулятор iPhone, источники данных, эталонные снимки |

## Внешние источники

| Источник | Для чего | Ключ |
|---|---|---|
| Jolpica (Ergast) | Зачёт, результаты, календарь, архив | Не нужен |
| Поток F1 Live Timing (SignalR) | Live Timing во время сессии | Не нужен |
| OpenF1 | Расписание сессий, запасной Live, фото пилотов | Не нужен |
| MultiViewer | Контуры трасс | Не нужен |
| Hugging Face (whisper.cpp), argos-net | Модели расшифровки и перевода (скачиваются по SHA-256) | Не нужен |
| Google ML Kit (телефон) | Перевод на устройстве | Не нужен, бесплатно |

## Риски, которые определили план проверки

1. **Данные из чужих ответов**: чужой ответ (в том числе подменённый в общественном Wi-Fi) может быть любого
   размера и содержания.
2. **Стык сезонов**: Jolpica «current» переключается на новый год раньше, чем появляется новый зачёт.
3. **Фоновые потоки**: обновление, Live, радио и уведомления пишут в одну базу.
4. **Четыре платформы, одна кодовая база**: пути, клавиши, жизненный цикл приложения и уведомления различаются.
5. **Нативный код**: декодер C, FFI в Dart, сторонние модели.
6. **Доступность**: четыре темы, крупный шрифт, «меньше движения».
