# Команда аудита

Аудит провёл Claude (Claude Code) с субагентами по направлениям. Субагенты искали и описывали проблемы;
каждую находку перед исправлением проверял основной агент: воспроизведением, расчётом или тестом.

| Роль | Что делал | Итог |
|---|---|---|
| Логика | Уведомления, титул, стык сезонов, прогнозы, прогон сезона по часам | BUG-1…BUG-7, S-1…S-4 |
| Безопасность | Вход из сети, пути и журнал, отчёт, CI, нативный код | SEC-1…SEC-9, CI-1 |
| Платформы | Различия Windows, macOS, Android, iPhone; пакеты и сборки | XP-1…XP-16 |
| Интерфейс и доступность | Контраст во всех темах, тексты, «назад», ширины | UX-1…UX-34 |
| Производительность | Скорость экранов, база под нагрузкой, сетевой хаос | [PERFORMANCE.md](PERFORMANCE.md) |
| Основной агент | Проверка находок, исправления, тесты, CI, отчёты | [FIXES.md](FIXES.md), [TEST_REPORT.md](TEST_REPORT.md) |

Находки субагентов с пометкой «подозрение» без воспроизведения в исправления не шли — они в
[BUGS.md](BUGS.md) со статусом Needs Review.
