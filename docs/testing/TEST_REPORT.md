## Что осталось

1. **Перевод радио на iPhone** — проверить на настоящем устройстве: на симуляторе модель ML Kit не скачивается.
2. **Проверки на устройствах**: будильники и виджет Android, ширины 320–360 px, жесты (UX-3, UX-4, UX-17, UX-18, UX-20).
3. **Решения дизайна**: подписи меню уже 400 px (UX-16) и красная полоска у заголовков разделов оставлены сознательно.
4. **Выравнивание по 16 КБ** — отчёт в CI: если библиотеки Python или плагинов не выровнены, это решают их авторы.

## Чего аудит не делал

- Не проверял на физических телефонах и iPhone — их нет. Результаты эмулятора и симулятора так и помечены.
- Не нагружал сторонние API и не менял настройки репозитория: защиту ветки и слияние PR блокирует система
  разрешений.
- Не удалял и не отключал тесты.
