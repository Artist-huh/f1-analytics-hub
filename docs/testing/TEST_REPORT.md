## Что осталось

По важности:

1. **XP-17, iPhone**: падение во время расшифровки на симуляторе. `ios_smoke` теперь собирает отчёты о падении
   (прогон `41984570956`). Следующий шаг — по отчёту найти место: декодер `radio_decode.c` через FFI,
   whisper.cpp на симуляторе или нехватка памяти. Скачивание перевода ML Kit на симуляторе тоже не отвечает;
   на устройстве это не проверено.
2. **UX-16**: подписи нижнего меню на телефонах уже 400 px.
3. **UX-10**: графики без описания для экранного диктора.
4. **XP-2, XP-9, XP-10** (Android): монохромная иконка уведомления, точные будильники, секундомер виджета.
5. Мелочи интерфейса UX-8, 9, 13, 14, 20…34 и подозрения S-1…S-4.

## Чего аудит не делал

- Не проверял на физических телефонах и iPhone — их нет. Результаты эмулятора и симулятора так и помечены.
- Не нагружал сторонние API и не менял настройки репозитория: защиту ветки и слияние PR блокирует система
  разрешений.
- Не удалял и не отключал тесты.
