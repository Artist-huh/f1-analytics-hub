# План тестирования

## Цель

Найти ошибки, которые видит пользователь, и уязвимости на всех платформах, исправить подтверждённые и
закрепить исправления автоматическими тестами.

## Границы

- Проверяется только этот репозиторий и его сборки в GitHub Actions.
- Реальные данные пользователя не трогаются: все тесты работают с временной базой (`F1_HUB_DB`) и выключенным
  журналом (`F1_HUB_LOG=off`).
- Чужие системы не атакуются. Сбои сети моделируются подменой ответов в процессе, а не нагрузкой на источники.
- Физических устройств нет. Android — эмулятор, iPhone — симулятор; это указано в каждом результате.

## Направления и способ проверки

| Направление | Как | Ответственный (см. [AGENTS.md](AGENTS.md)) |
|---|---|---|
| Функциональность и логика | Чтение кода, модульные тесты с подставными данными, прогон сезона по часам | Логика |
| Кроссплатформенность | Чтение кода по платформам, сборки и запуск в CI (Windows, macOS, эмулятор Android, симулятор iPhone) | Платформы |
| Браузеры | Не применимо: веб-сборки нет | — |
| Адаптивность | Снимки окна на 11 размерах (`/shots`), крупный шрифт ×1.3 | Интерфейс |
| Нагрузка и стабильность | 6 потоков × 30 с на базу, 5700 построений экранов, сетевой хаос | Производительность |
| Безопасность | Чтение кода (вход из сети, пути, журнал, CI), проверка пределов | Безопасность |
| Производительность | Время построения экранов, загрузка состояния, размер сборки, время радио | Производительность |
| UI/UX и доступность | Контраст по WCAG во всех темах, тексты, зоны нажатия, «назад» | Интерфейс |
| Регрессия | Полный набор тестов после каждого исправления, CI | Все |

## Критерии

- **Passed** — проверено и работает.
- **Failed** — проверено, не работает (ошибка в [BUGS.md](BUGS.md)).
- **Blocked** — проверить нельзя (нет среды или устройства).
- **Not Tested** — не проверялось.
- **Needs Review** — проверено частично или по коду, нужна проверка на устройстве или человеком.

Исправление считается готовым, когда есть тест, который падает без исправления и проходит с ним, весь набор
тестов зелёный и `ruff` чист.
