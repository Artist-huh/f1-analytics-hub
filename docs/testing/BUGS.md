# Найденные проблемы

Серьёзность: **High** — неверные данные или сбой у многих пользователей; **Medium** — заметная ошибка или
риск; **Low** — мелочь. Статус: **Fixed** (есть тест и коммит, см. [FIXES.md](FIXES.md)), **Open**,
**Needs Review** (нужна проверка на устройстве).
