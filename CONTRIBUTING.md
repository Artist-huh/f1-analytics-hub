# Вклад в проект

Спасибо за интерес к улучшению F1 Analytics Hub! 🏎️

## Как помочь проекту

### 🐛 Сообщить об ошибке

1. Проверьте, что похожая ошибка еще не была [создана](https://github.com/Artist-huh/f1-analytics-hub/issues)
2. Используйте шаблон "Bug Report"
3. Опишите шаги для воспроизведения
4. Приложите скриншоты, если возможно
5. Укажите вашу систему (Windows/macOS/Linux)

### 💡 Предложить улучшение

1. Откройте [Issue](https://github.com/Artist-huh/f1-analytics-hub/issues)
2. Опишите идею и зачем она нужна
3. Приложите mockup-ы, если есть

### 🔧 Внести код

1. **Fork** репозитория
2. Создайте **ветку** для вашей фичи: `git checkout -b feature/amazing-feature`
3. **Commit** изменения: `git commit -m 'Add amazing feature'`
4. **Push** в ветку: `git push origin feature/amazing-feature`
5. Откройте **Pull Request**

## Стандарты кода

### Python

- **Стиль**: PEP 8
- **Форматтер**: Black (line length 100)
- **Linter**: Flake8
- **Type hints**: приветствуются

```bash
# Установить dev-зависимости
pip install black flake8 mypy

# Отформатировать код
black .

# Проверить стиль
flake8 .

# Type checking
mypy main.py
```

### Структура коммита

```
<тип>: <краткое описание>

<подробное описание (опционально)>

<футер (опционально)>
```

**Типы:**
- `feat` — новая функция
- `fix` — исправление ошибки
- `docs` — документация
- `style` — форматирование, пробелы
- `refactor` — рефакторинг без изменения функционала
- `test` — добавление тестов
- `chore` — обслуживание, обновление зависимостей

**Примеры:**

```
feat: добавить фильтр по командам на экране пилотов

Пользователи теперь могут отфильтровать пилотов по конкретной команде
через цветные чипы над списком.
```

```
fix: исправить падение при отсутствии интернета

Добавлена проверка сетевых ошибок в api.fetch_standings().
Приложение теперь показывает cached данные вместо краша.
```

## Процесс Review

1. **Automated checks** — CI должен пройти (linting, tests)
2. **Code review** — минимум 1 одобрение от maintainer'а
3. **Testing** — проверьте вручную на вашей системе
4. **Documentation** — обновите README/docs если нужно

## Области для вклада

### 🟢 Good First Issues

Простые задачи для новичков:
- Добавить переводы (интернационализация)
- Улучшить сообщения об ошибках
- Добавить unit-тесты
- Исправить опечатки в документации

### 🟡 Средние задачи

- Реализовать экспорт данных в CSV/PDF
- Добавить больше графиков и статистики
- Улучшить производительность загрузки
- Создать светлую тему

### 🔴 Сложные задачи

- Реализовать live-обновления во время гонки
- Добавить ML-предсказания результатов
- Портировать на мобильные платформы
- Интеграция с другими API (Twitter, Instagram)

## Тестирование

### Ручное тестирование

1. Запустите приложение: `python main.py`
2. Проверьте все экраны
3. Попробуйте edge-cases:
   - Нет интернета
   - Медленное соединение
   - Пустая база данных
   - Разные разрешения экрана

### Автоматическое

```bash
python -m unittest discover -s tests -t .
```

Тесты не ходят в сеть и не трогают вашу базу (`F1_HUB_LOG=off` отключает запись журнала в файл).
