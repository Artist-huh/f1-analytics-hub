# F1 Analytics Hub — Итоги переработки

## 2.1.0 (2026-10-23) — восемь новых функций

- **Live-тайминг** (OpenF1): позиции, отрывы и интервалы, шины и их возраст, пит-стопы, сообщения
  дирекции гонки; обновление каждые 10 с во время сессии, баннер LIVE на главной.
- **Уведомления**: за час до квалификации, спринта и гонки, итоги избранных после гонки. Windows/macOS/Linux —
  desktop-notifier (в .exe собирается с `--collect-all desktop_notifier`), Android — NotificationManager
  через pyjnius, иначе — плашка в приложении. Работают, пока приложение запущено.
- **История с 1950 года**: сезон любого года (чемпион, зачёты, победители гонок), чемпионы всех лет и
  рекорды по титулам. Сезоны загружаются по запросу и кэшируются; список чемпионов встроен.
- **Страница команды**: логотип и болид, показатели сезона, дуэль напарников, график очков.
- **Статистика трасс**: схема трассы, первый Гран-при, рекордсмены, лучший круг в гонке, победители и поулы.
- **Темы**: тёмная, светлая, в цветах команды — переключаются без перезапуска.
- **Борьба за титул**: кто ещё может стать чемпионом и что нужно лидеру для досрочного титула.
- **Мини-виджет** для компьютера (Ctrl+M). Виджет рабочего стола Android во Flet невозможен.
- Схема БД v4 (таблица `archive`, идентификаторы трасс); 93 теста.

## 2.0.0 (2026-10-23) — универсальное F1-приложение

**Дизайн.** Палитра Формулы-1: красный `#E10600` на чёрном `#15151E`, красные градиенты, свечение,
мягкие тени. Шрифт Exo 2 (Barlow Condensed не поддерживал кириллицу — русские заголовки рисовались
системным шрифтом). Плавная смена экранов, появление карточек «лесенкой», подъём и подсветка при
наведении, «рябь» при нажатии. Новая иконка — собственный знак «F1» в красно-чёрных тонах (`tools/make_icon.py`).

**Никакого «главного» пилота.** Убраны константа `LECLERC_ID`, экран «Дуэль с Леклером» и загрузка
результатов одного пилота. Приложение загружает результаты, квалификации и спринты всего сезона по
всем пилотам; страница любого пилота открывается мгновенно и без сети. Папка данных —
`~/.f1_analytics_hub` (старая база переносится, избранное и настройки сохраняются).

**Фото и логотипы.** Официальные портреты пилотов на прозрачном фоне (на градиенте цвета команды),
флаги стран, логотипы и изображения болидов команд. Дисковый кэш, запасное фото, инициалы без сети;
картинки сезона встроены в сборку для первого запуска офлайн.

**Сравнение 2–4 пилотов.** 13 показателей (очки, победы, подиумы, поулы, быстрые круги, топ-10, сходы,
лучший/средний финиш, средняя квалификация, очки за гонку, отыгрыш со старта) с подсветкой лучшего,
график набора очков, личные встречи в гонках и квалификациях, быстрые наборы (топ-N, напарники, избранные).

**Новое на экранах.** Подиум последней гонки на главной и у прошедших этапов календаря; страница пилота
с поулами, быстрыми кругами, средним финишем и графиком против напарника; карточки команд с пилотами и болидом.

**Android.** `pyproject.toml` для `flet build apk`, сборка APK в GitHub Actions, адаптивная иконка и
сплэш, SafeArea, зоны нажатия 48 px, компактная вёрстка на телефоне, системная кнопка «назад».

**Исправлено попутно.** Результаты сезона перезапрашиваются один раз на новый этап, а не на каждом
цикле обновления (иначе — 10 лишних запросов к API каждые 5 минут).

## 2026-10-23 — обновление зависимостей и CI

- Flet 0.86.5 → 1.0.5. Рамки полей ввода и списков переведены на `border=OutlineInputBorder(...)`
  (`border_color`/`focused_border_color` устарели и удаляются во Flet 1.3). Проверено в настоящем окне:
  все экраны и 112 обработчиков, включая кнопки диалогов, без ошибок и предупреждений.
- GitHub Actions: `checkout`, `setup-python`, `upload-artifact` → v7 (Node.js 24); заархивированный
  `upload-release-asset` заменён на `gh release upload`; macOS-сборка через `flet pack`.
- Горячие клавиши: F5, Ctrl+F, Ctrl+K, Esc.
- `python -m services.seed` больше не падает на консоли без кириллицы (cp1252).
- Тесты интерфейса дожидаются фоновых потоков вместо `sleep` — убрано редкое падение WinError 32.

## 2026-10-22 — тестирование и исправления

- Новые экраны переведены на API Flet 0.80+ (`ft.Alignment`, `ft.Padding`, `ft.Border`, `page.show_dialog`
  и т.д.) и на реальную схему данных из БД — раньше падали 7 из 12 экранов.
- Перерисовка из фоновых потоков идёт через `page.run_task`: фоновое обновление данных и таймер отсчёта
  теперь действительно обновляют окно.
- Календарь подключён (была заглушка), трассы определяются по названию автодрома.
- Страница пилота: реальные подиумы/сходы/лучший финиш, график очков, результаты; данные любого пилота
  загружаются по требованию. Сравнение: числовое сравнение позиций, head-to-head по результатам.
- Поиск пилотов не теряет фокус при вводе; адаптивная сетка; ограничение ширины контента на широких окнах,
  компактный режим < 400 px.
- Подтверждение перед очисткой базы; «назад» возвращает на предыдущий экран.
- Удалены неработающие и неиспользуемые модули (`home_new.py`, `home_fixed.py`, `season_fixed.py`,
  `charts.py`, `services/assets.py`, ручной `F1AnalyticsHub.spec`, `build_windows.bat`).
- Сборка: `build.bat` → `flet pack` (без ошибок и предупреждений), шрифт и иконка в `assets/`.
- Тесты: 53 теста, исправлена нестабильность из-за фонового потока (`f1_api.shutdown()`).
